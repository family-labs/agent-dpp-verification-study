# Working notes

These four files are internal notes written while the study was being built and run. They are
not results and they are not part of the registered plan.

- `HANDOVER.md` and `ORCHESTRATOR_HANDOFF.md`: hand-over notes between working sessions.
- `RUNBOOK-2026-09-22.md`: the steps for rebuilding the Study 1 fixtures. Study 1 was retired
  before any trial.
- `STUDY6-LIVE-PLAN.md`: the working plan for the live-site version of Study 6. The registered
  plan is amendment A36 in `PREREGISTRATION.md`.

Each note describes the state of the work on the day it was written. Statements such as "no
trial has run" were true then and are not true now. The files are kept because
`PREREGISTRATION.md` and the amendment drafts cite them by name. They sat in the top folder of
the private repository and are cited there by their file names alone.
